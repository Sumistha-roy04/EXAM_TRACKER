# Exam Sprint (Android app)

1. Create a new GitHub repository and upload everything in this folder (keep the `.github` folder).
2. Open the repository's Actions tab. The "Build APK" run starts by itself (about 5 minutes).
3. When it finishes, open the run and download the `exam-sprint-apk` artifact. Unzip it to get `app-debug.apk`.
4. Send the APK to your phone and install it (allow "install unknown apps" when asked).

Progress is saved on the phone only. To change the app, edit `www/index.html` and push again.
